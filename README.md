
# 📁 Tkinter File Explorer

A simple **File Explorer application built using Python and Tkinter**.
This project allows users to browse files from their system and open **text files** to view their content inside a GUI.

---

## 🚀 Features

* 📂 Browse files using system file dialog
* 📄 Open and read `.txt` files
* 🖥️ Display file path in the UI
* 📝 Show file content inside the application
* ⚠️ Error handling using message boxes
* 🧼 Clean and beginner-friendly interface

---

## 🛠️ Technologies Used

* **Python 3**
* **Tkinter (GUI)**
* Built-in modules:

  * `filedialog`
  * `messagebox`

## ▶️ How to Run the Project

1. Make sure **Python 3** is installed
2. Clone the repository:

   ```bash
   git clone https://github.com/shaafiqbal/tkinter_file_explorer.git
   ```
3. Navigate to the project folder:

   ```bash
   cd tkinter_file_explorer
   ```
4. Run the application:

   ```bash
   python main.py
   ```
